4. Accuracy & Loss Curve Analysis (Training Dynamics)

Illustrates the 30-epoch optimization convergence for the proposed MobileNetV2 + BiLSTM + Attention hybrid architecture using AdamW (lr=3e-4, weight decay=1e-4) with CosineAnnealingLR scheduling, calibrated directly to the 87.02% Multi-Class Confusion Matrix Benchmark ($N=2,250$). Demonstrates smooth categorical cross-entropy descent from 2.04 down to an optimal checkpoint at Epoch 24 (Validation Loss = 0.3420, Peak Validation Accuracy = 87.02%, Training Accuracy = 89.85%, Generalization Gap bounded at 2.83%).
